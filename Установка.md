# Наборы правил: инструкция по установке

Установите расширение через **Настройки → Расширения → Добавить расширение**, указав адрес:

```text
https://github.com/chenyuhao0628/openchamber-agents
```

openchamber-agents **0.1.6** · Требуется OpenChamber **2.4.0 или новее**.

Расширение позволяет хранить несколько наборов глобальных правил `AGENTS.md`, редактировать их, просматривать построчные различия перед активацией, создавать резервные копии и восстанавливать прежние версии. Текущее состояние отображается в разделе статуса работы. Расширение управляет текстом правил, а не выбором агентов или моделей OpenCode.

**Сохранение набора не активирует его.** Глобальный файл изменяется только после подтверждения в окне предварительного просмотра активации. Перед записью расширение автоматически создаёт резервную копию исходного текста.

> Интерфейс панели пока доступен только на китайском. Ниже рядом с переводами приведены названия основных элементов интерфейса.

## Установка

1. В OpenChamber откройте **Настройки → Расширения → Добавить расширение** и вставьте Git URL, указанный выше. Вместо URL можно выбрать папку `openchamber-agents` или ZIP-архив для ручной установки. Проверка обновлений на странице настроек доступна только при установке по Git URL; установки из папки и ZIP автоматически не обновляются.
2. Подтвердите доступ к следующим файлам и включите расширение:

   | Область доступа | Назначение |
   | --- | --- |
   | `~/.config/opencode/AGENTS.md` | Чтение и замена глобальных правил по вашему действию |
   | `~/.config/openchamber/agents-manager/**` | Библиотека наборов, резервные копии и экспорт |

3. Нажмите значок **«Наборы правил» (`规则方案`)** на правой боковой панели. Если значок не появился, перезагрузите интерфейс.

При ошибке `host-too-old` сначала обновите OpenChamber, затем повторите установку.

## Основные действия

- При первом открытии панели текущие глобальные правила импортируются в отдельный набор. Сам файл при этом не изменяется.
- Создание, копирование и импорт файлов `.md` или `.txt` создают черновик. Кнопка **«Сохранить набор» (`保存方案`)** обновляет только библиотеку.
- Кнопка **«Предпросмотр активации» (`预览启用`)** показывает построчные различия с глобальным файлом. После подтверждения расширение создаёт резервную копию, записывает текст и повторно читает файл для проверки.
- В разделе **«Резервные копии» (`备份`)** можно просмотреть и восстановить прежнюю версию. Перед восстановлением также создаётся копия текущего файла.

Библиотека, резервные копии и экспорт хранятся в `~/.config/openchamber/agents-manager/`. Все указанные пути обслуживает **сервер OpenChamber, к которому вы сейчас подключены**. При удалённом подключении это пути на сервере, а не на вашем компьютере.

## Известные ограничения

- Если путь проекта содержит китайские или другие символы вне Latin-1, OpenChamber 2.4.0 может выдавать ошибку при чтении глобального файла. Начиная с версии расширения 0.1.5 причина поясняется на китайском, а уже загруженное содержимое сохраняется. Временное решение: открыть панель в сеансе без проекта или в проекте, путь которого не содержит таких символов.
- В сеансе без проекта кнопка **«Управление» (`管理`)** в разделе статуса работы может не реагировать. Используйте значок **«Наборы правил» (`规则方案`)** справа.
